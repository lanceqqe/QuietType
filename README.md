# QuietType

Нативное локальное автодополнение для **macOS 26+ на Apple Silicon**. Русский и английский, без Apple Intelligence, Python, Ollama и облачных API во время работы.

## Запуск

Готовое приложение: `dist/QuietType.app`.

1. Переместите приложение в `/Applications` перед выдачей разрешений. Смена пути или пересборка с временной подписью может потребовать повторной выдачи разрешения macOS.
2. Запустите QuietType. В разделе **Модель** нажмите **Скачать модель**. Загрузка — примерно 1,43 ГБ (19 файлов); проверяются размер и SHA-256 каждого файла и фиксируется ревизия источника. После установки интернет не нужен. Первый запуск модели занимает полторы-две минуты: Core ML один раз подготавливает её для Neural Engine, дальше загрузка занимает около секунды.
3. В **Приложения** разрешите **Универсальный доступ** и при необходимости **Мониторинг ввода**, затем нажмите **Проверить разрешения**. QuietType не выдаёт себе разрешения самостоятельно.
4. Откройте TextEdit, напишите несколько слов, сделайте паузу. Подсказка появится рядом с курсором, если поле предоставляет необходимые Accessibility-атрибуты.

Проверочный редактор внутри QuietType работает без системных разрешений. Нажмите «Продолжить» или измените текст и дождитесь подсказки.

| Действие | Клавиши |
|---|---|
| Принять следующее слово | Tab |
| Принять всю подсказку во внешнем приложении | Option + Tab |
| Скрыть подсказку | Escape |
| Запросить продолжение во внешнем приложении | Control + Option + Пробел |
| Пауза / возобновление | Переключатель в строке меню |

Tab сохраняет обычное действие, когда подсказки нет. Пока подсказка видна, Tab всегда принадлежит QuietType — в том числе в браузерах: клавиша перехватывается до приложения, без повторных запросов к нему. Для перехода к следующему полю при показанной подсказке сначала нажмите Escape. Если набирать те же символы, что в подсказке, её остаток остаётся на месте без нового запроса к модели.

## Установщик и релизы

- `./scripts/make-dmg.sh` собирает `dist/QuietType-<версия>.dmg`: приложение, ярлык «Программы» и «Как установить.txt». Модель в образ не входит, приложение скачивает её само.
- Сборка не заверена Apple (нет Developer ID): при первом запуске получателю нужно нажать «Всё равно открыть» в настройках безопасности; шаги описаны в файле внутри образа.
- `./scripts/release.sh` публикует версию из `scripts/Info.plist` как релиз GitHub с DMG. Установленные копии обновятся сами. Релизы нужно подписывать одним и тем же сертификатом, иначе обновление будет отклонено.

## Реализация

- Swift 6, SwiftUI, AppKit и публичный Accessibility API. Без Electron и веб-интерфейса.
- Модель [ANEMLL Gemma 3 1B (it), ctx4096](https://huggingface.co/anemll/anemll-google-gemma-3-1b-it-ctx4096_0.3.5), 6-битные FFN и LM head; QuietType использует до 512 токенов контекста. Веса распространяются на [условиях Gemma](https://ai.google.dev/gemma/terms), это не open-source лицензия. Токенизатор — Hugging Face swift-transformers.
- `LocalModel` сам определяет раскладку ANEMLL в каталоге модели: число чанков FFN (у каждого свой KV-кэш), ширину маски, вид LM head (полные логиты или argmax по срезам словаря), стоп-токены и BOS. Пороги уверенности задаются на модель (`ModelAssets.profile`).
- Модель загружается с `computeUnits = .cpuAndNeuralEngine`. Это разрешение для планировщика Core ML, **не гарантия 100% исполнения на ANE**. Если Core ML на данном Mac отказывается загрузить функции модели для Neural Engine (наблюдалось на M1 Pro, macOS 27.0), те же файлы загружаются на CPU + GPU, затем на CPU. На GPU первая генерация занимает около 25 с (её берёт на себя прогрев при загрузке), дальше 0,5–2 с на подсказку. Фактическое устройство показано в разделе **Модель**.
- **Почерк** (`StyleMemory`, выключен по умолчанию): из набранного пользователем текста собираются словарь, частые связки слов и до 300 последних фраз. Уверенная личная привычка (связка встречалась ≥3 раз) показывается сразу, без модели; иначе модель получает до 400 символов фраз пользователя перед контекстом поля как образец стиля. Блок фраз фиксирован, пока приложение на переднем плане, поэтому KV-кэш его переживает.
- **Обновление** (`Updater`): при запуске и раз в сутки запрашивается последний релиз GitHub. DMG устанавливается, только если SHA-256 совпал с релизом и подпись удовлетворяет designated requirement работающей копии.
- Батчевый prefill на 64 токена, переиспользование KV-кэша общего префикса, ранний показ законченных слов. Не отправляется запрос на каждый символ: нажатия отменяют предыдущую задачу, после паузы запускается новая.
- Автоматический режим: пауза 110 мс, до 3 слов. Быстрый: 50 мс, до 3 слов. Экономия / Low Power / сильный нагрев: 400 мс, до 2 слов. Окно контекста (до 900 символов) сдвигается блоками, поэтому KV-кэш переживает набор длинного текста.
- Декодер заново предсказывает слово под курсором (а не доверяет токенизации обрывка), не повторяет последовательности токенов, уже встречавшиеся в тексте, и обрывает подсказку на последнем законченном слове, когда модель не уверена. Если уверенного продолжения нет, подсказка не показывается. Генерация останавливается на границе нужного количества слов; внутренний лимит 16/8 токенов дополнительно ограничивает вычисления. При критическом нагреве генерация останавливается.
- Нет таймера опроса текста или постоянной генерации. Наблюдение за полем начинается даже до первого символа; для редакторов без AX-уведомлений есть один отменяемый отложенный запрос по событию клавиши. Модель можно явно выгрузить из памяти.
- Установка модели идёт во временный каталог; после проверки файлов каталог заменяется целиком. Отмена не оставляет частично установленную модель.

## Приватность и совместимость

Текст полей и подсказки хранятся только в оперативной памяти. Нет истории набора, телеметрии текста, скриншотов или обращений к облачным моделям. Кэш ограничен восемью подсказками и очищается при смене фокуса и паузе. Контекст поля ограничен; распознанные форматы ключей и паролей отбрасываются, но этот фильтр не распознаёт все виды секретов.

Парольные поля, менеджеры паролей и терминалы отключены по умолчанию. Пользовательские исключения задаются bundle ID в разделе «Приложения». Подсказка сбрасывается при любой клавише, клике, смене фокуса или изменении текста; перед вставкой проверяется активный процесс. Вставка использует Accessibility либо Unicode keyboard events; буфер обмена не меняется.

Нестандартные редакторы, canvas-поля и некоторые веб-приложения могут не предоставлять текст или координаты курсора. Если поле отдаёт текст, но не координаты курсора, подсказка показывается плашкой рядом с полем. Если приложение отдаёт координаты курсора вне поля, подсказка тоже уходит в плашку. Telegram для macOS сообщает прямоугольник курсора ровно на строку выше текста — для него координата поправляется, и подсказка рисуется в строке. Для приложений, которые совсем прячут поле (список `KeystrokeFallback.bundleIDs`, сейчас пуст), есть режим по набранным клавишам: буфер только в памяти, сбрасывается при любом действии, после которого позиция курсора неизвестна, и не ведётся при Secure Input. Для Chromium и Electron QuietType включает их дерево Accessibility (`AXManualAccessibility`), вставка в веб-поля идёт клавиатурными Unicode-событиями. Это первая рабочая версия, а не заявленная полная совместимость Cotypist. Подсказка отображается приглушённым текстом в продолжение строки, с переносом по ширине поля. Рамки и фона нет, документ не меняется до принятия. Внешнее отображение использует прозрачный non-activating drawing surface, который не забирает фокус и клики. Шрифт и цвет читаются через Accessibility, если приложение их предоставляет; иначе используются размеры курсора и системный шрифт.

Модель на 1 млрд параметров (6 бит) остаётся главным ограничением качества: подсказки стали связными, но встречаются неверные окончания слов и банальные продолжения (см. сравнение ниже). Это чат-модель, которой текст подаётся без шаблона чата; дообученной под автодополнение модели нет. Персонализация и контекст экрана не реализованы; разрешение на запись экрана не запрашивается.

### Журнал

`~/Library/Logs/QuietType.log` (текущий запуск) и `QuietType.previous.log` (предыдущий): версия, macOS, чип, этапы конвейера, длины, время модели, ошибки загрузки модели и обновления с кодами Core ML. Набранный текст и подсказки в журнал не попадают. Пункт меню «Показать журнал для отчёта об ошибке» выделяет оба файла в Finder.

### Память почерка

Файл `~/Library/Application Support/QuietType/Memory/style.json` (права 0600), только на этом Mac. Запоминается лишь набранное с клавиатуры в полях, где работают подсказки, и принятые подсказки. Не запоминаются: вставленный текст, парольные поля и Secure Input, исключённые приложения, слова с цифрами, ссылки, адреса, строки, похожие на секреты. «Забыть всё» в разделе **Почерк** удаляет файл.

## Сборка и проверка

Нужны Xcode с macOS 26+ SDK и Swift 6.2+. Зависимости фиксирует `Package.resolved`.

```sh
swift test
./scripts/build-app.sh
open dist/QuietType.app
```

Файлы весов не включены в Git и `.app`. Для установки уже скачанного каталога с проверкой контрольных сумм:

```sh
swift run ModelProbe --install .model-cache/gemma1b
```

Проверка реальной генерации из установленной модели:

```sh
swift run -c release ModelProbe
```

Probe выводит только встроенные тестовые фразы. Для каждого примера он сравнивает результат при тёплом KV-кэше с результатом после сброса; несовпадение завершает проверку с ошибкой. Свои фразы и другая модель в раскладке ANEMLL:

```sh
swift run -c release ModelProbe --model <каталог> --floors 0.3,0.3,0.2 --try "Спасибо за письмо. Мы свяжемся с вами"
```

Скрипт использует единственный доступный сертификат Apple Development, если он есть, иначе локальную ad-hoc подпись. Явный выбор задаётся `QUIETTYPE_SIGN_IDENTITY`. Текущая сборка подписана имеющимся сертификатом разработчика; это сохраняет её идентичность между пересборками. При смене ad-hoc подписи на сертификат macOS может потребовать удалить устаревшую запись Accessibility и заново запросить доступ. Кнопка «Запросить доступ…» вызывает публичный системный запрос, добавляющий приложение в список; включение переключателя остаётся действием пользователя. Для распространения другим пользователям нужны Developer ID, hardened runtime и нотариализация. На macOS 26 проект компилируется по deployment target; фактические проверки в этой сессии выполнялись на macOS 27.2 / Apple M5.

## Результаты проверки

### Сравнение моделей (10 ноября 2026, Apple M5)

Один и тот же декодер, 20 фраз (12 русских, 8 английских, 6 оборваны посреди слова), до 3 слов, холодный KV-кэш на каждую фразу, после прогрева модели. Время — только вызов модели.

| | Qwen3 0.6B (была) | Qwen3 1.7B | **Gemma 3 1B (выбрана)** |
|---|---|---|---|
| Загрузка | 0,76 ГБ | 1,95 ГБ | 1,43 ГБ |
| Время вызова, 20 фраз | 40–146 мс | 133–713 мс | 49–132 мс |
| На токен | ≈15 мс | ≈40 мс | ≈16 мс |
| «…Мы свяжемся с вами» | в ближней районе. | в ближайшее время. | в ближайшее время. |
| «Извините за задержку с отве» | …отве**лем на** | …отве**том.** | …отве**том.** |
| «Отправляю вам документы на соглас» | …соглас**ие,** | …соглас**ование с** | …соглас**ность.** |
| «…купить молоко и» | (пусто) | кефир, и я | хлеб. |
| «…поэтому я решил» | сходить к врачу. | пойти в парк. | поехать в горы. |
| «Давай встретимся завтра и обсудим» | обсуждение о | , как мы | , как можно |
| «I'm sorry for the late repl» | …repl**y.** | …repl**y.** | …repl**ies.** |
| «Could you please send me the» | (пусто) | (пусто) | following information? |

- Qwen3 1.7B пишет по-русски не хуже Gemma и лучше дописывает оборванные слова, но в 200 мс не укладывается: два чанка FFN дают ≈40 мс на токен, типичная подсказка — 280–520 мс.
- Gemma 3 1B укладывается в бюджет и на этих фразах не дала ни одной бессмысленной русской подсказки. Замеченные ошибки: «на согласность» вместо «на согласование», «late replies» вместо «late reply». Причина — LM head этой конвертации отдаёт не все логиты, а лучший токен каждого из 16 срезов словаря, поэтому при дописывании слова под курсором выбор идёт из 16 кандидатов, а не из 32 лучших.
- Из-за того же argmax-head «вероятность» токена у Gemma — оценка сверху (нормировка по 16 максимумам). Пороги обрыва пересчитаны под неё: 0,30 для первого токена и начала слова, 0,20 внутри слова (у Qwen3 0.6B были 0,09 / 0,08 / 0,05 по настоящему softmax).
- Gemma 3 4B (4,4 ГБ, три чанка FFN) не скачивалась и не измерялась; при трёх чанках против двух у Qwen3 1.7B в 200 мс она, скорее всего, не уложится.
- Это 20 фраз, просмотренных глазами, а не метрика качества; живой набор в приложениях на новой модели в этой сессии не проверялся.

### Более ранние замеры (Qwen3 0.6B)

Первые реальные проверки на Apple M5: около 270–435 мс для 12 токенов и 163–199 мс для 8 токенов с общим префиксом. Эти числа относятся к вызову модели, исключают паузу debounce и загрузку модели; они не являются сравнением с Cotypist. Потребление энергии и доля операций на Neural Engine отдельно не измерены.

См. `docs/VALIDATION.md` для текущего протокола проверки и `THIRD_PARTY_NOTICES.md` для источников и лицензий.
