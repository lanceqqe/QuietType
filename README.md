# QuietType

Нативное локальное автодополнение для **macOS 26+ на Apple Silicon**. Русский и английский, без Apple Intelligence, Python, Ollama и облачных API во время работы.

## Запуск

Готовое приложение: `dist/QuietType.app`.

1. Переместите приложение в `/Applications` перед выдачей разрешений. Смена пути или пересборка с временной подписью может потребовать повторной выдачи разрешения macOS.
2. Запустите QuietType. В разделе **Модель** нажмите **Скачать модель**. Загрузка — примерно 800 MB (763 MiB); проверяется SHA-256 каждого файла и фиксируется ревизия источника. После установки интернет не нужен. Первый запуск модели может занимать около минуты.
3. В **Приложения** разрешите **Универсальный доступ** и при необходимости **Мониторинг ввода**, затем нажмите **Проверить разрешения**. QuietType не выдаёт себе разрешения самостоятельно.
4. Откройте TextEdit, напишите несколько слов, сделайте паузу. Подсказка появится рядом с курсором, если поле предоставляет необходимые Accessibility-атрибуты.

Проверочный редактор внутри QuietType работает без системных разрешений. Нажмите «Продолжить» или измените текст и дождитесь подсказки.

| Действие | Клавиши |
|---|---|
| Принять следующее слово | Tab |
| Принять всю подсказку во внешнем приложении | Option + Tab |
| Скрыть подсказку | Escape |
| Запросить продолжение во внешнем приложении | Control + Option + Пробел |
| Пауза / возобновление | Переключатель в строке меню |

Tab сохраняет обычное действие, когда подсказки нет. Для перехода к следующему полю при показанной подсказке сначала нажмите Escape.

## Реализация

- Swift 6, SwiftUI, AppKit и публичный Accessibility API. Без Electron и веб-интерфейса.
- Модель [ANEMLL Qwen3 0.6B, ctx512](https://huggingface.co/anemll/anemll-Qwen3-0.6B-ctx512_0.3.0), 6-битные FFN и LM head. Токенизатор — Hugging Face swift-transformers.
- Все части модели загружаются с `MLModelConfiguration.computeUnits = .cpuAndNeuralEngine`. GPU не входит в разрешённые устройства. Это разрешение для планировщика Core ML, **не гарантия 100% исполнения на ANE**.
- Батчевый prefill на 64 токена, переиспользование KV-кэша общего префикса, ранний показ законченных слов. Не отправляется запрос на каждый символ: нажатия отменяют предыдущую задачу, после паузы запускается новая.
- Автоматический режим: пауза 400 мс, до 3 слов. Быстрый: 220 мс, до 3 слов. Экономия / Low Power / сильный нагрев: 700 мс, до 2 слов. Генерация останавливается на границе нужного количества слов; внутренний лимит 16/8 токенов дополнительно ограничивает вычисления. При критическом нагреве генерация останавливается.
- Нет таймера опроса текста или постоянной генерации. Наблюдение за полем начинается даже до первого символа; для редакторов без AX-уведомлений есть один отменяемый отложенный запрос по событию клавиши. Модель можно явно выгрузить из памяти.
- Установка модели идёт во временный каталог; после проверки файлов каталог заменяется целиком. Отмена не оставляет частично установленную модель.

## Приватность и совместимость

Текст полей и подсказки хранятся только в оперативной памяти. Нет истории набора, телеметрии текста, скриншотов или обращений к облачным моделям. Кэш ограничен восемью подсказками и очищается при смене фокуса и паузе. Контекст поля ограничен; распознанные форматы ключей и паролей отбрасываются, но этот фильтр не распознаёт все виды секретов.

Парольные поля, менеджеры паролей и терминалы отключены по умолчанию. Пользовательские исключения задаются bundle ID в разделе «Приложения». Перед вставкой повторно проверяются процесс, фокус, выделение и контекст. Вставка использует Accessibility либо Unicode keyboard events; буфер обмена не меняется.

Нестандартные редакторы, canvas-поля и некоторые веб-приложения могут не предоставлять текст или координаты курсора. Без координат подсказки не показываются. Это первая рабочая версия, а не заявленная полная совместимость Cotypist. Подсказка отображается приглушённым текстом в продолжение строки, с переносом по ширине поля. Рамки и фона нет, документ не меняется до принятия. Внешнее отображение использует прозрачный non-activating drawing surface, который не забирает фокус и клики. Шрифт и цвет читаются через Accessibility, если приложение их предоставляет; иначе используются размеры курсора и системный шрифт.

Компактная модель иногда предлагает неудачные формулировки, особенно на русском. Уверенность, персонализация, альтернативные модели и контекст экрана пока не реализованы. Контекст экрана и сравнение моделей отложены по просьбе пользователя; разрешение на запись экрана не запрашивается.

## Сборка и проверка

Нужны Xcode с macOS 26+ SDK и Swift 6.2+. Зависимости фиксирует `Package.resolved`.

```sh
swift test
./scripts/build-app.sh
open dist/QuietType.app
```

Файлы весов не включены в Git и `.app`. Для установки уже скачанного каталога с проверкой контрольных сумм:

```sh
swift run ModelProbe --install .model-cache/anemll
```

Проверка реальной генерации из установленной модели:

```sh
swift run -c release ModelProbe
```

Probe выводит только встроенные тестовые фразы. Для каждого примера он сравнивает результат при тёплом KV-кэше с результатом после сброса; несовпадение завершает проверку с ошибкой.

Скрипт использует единственный доступный сертификат Apple Development, если он есть, иначе локальную ad-hoc подпись. Явный выбор задаётся `QUIETTYPE_SIGN_IDENTITY`. Текущая сборка подписана имеющимся сертификатом разработчика; это сохраняет её идентичность между пересборками. При смене ad-hoc подписи на сертификат macOS может потребовать удалить устаревшую запись Accessibility и заново запросить доступ. Кнопка «Запросить доступ…» вызывает публичный системный запрос, добавляющий приложение в список; включение переключателя остаётся действием пользователя. Для распространения другим пользователям нужны Developer ID, hardened runtime и нотариализация. На macOS 26 проект компилируется по deployment target; фактические проверки в этой сессии выполнялись на macOS 27.2 / Apple M5.

## Результаты проверки

Первые реальные проверки на Apple M5: около 270–435 мс для 12 токенов и 163–199 мс для 8 токенов с общим префиксом. Эти числа относятся к вызову модели, исключают паузу debounce и загрузку модели; они не являются сравнением с Cotypist. Потребление энергии и доля операций на Neural Engine отдельно не измерены.

См. `docs/VALIDATION.md` для текущего протокола проверки и `THIRD_PARTY_NOTICES.md` для источников и лицензий.
