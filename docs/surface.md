# Main window

Mode: Operate. The requested Apple Silicon Mac utility follows native macOS design conventions. Code-first app screen.

## Direction contract
THESIS: A small writing utility whose setup, actual model state and writing test are immediately accessible.
OWN-WORLD: System materials, semantic foregrounds, native sidebar, SF typography and SF Symbols; one system teal accent for assistance.
STORY: Install the model, grant access, try a Russian sentence, return to writing. Errors show a recovery action.
FIRST VIEWPORT: Sidebar with Overview, Writing, Model, Energy and Applications. Main pane leads with the current readiness and next action. A large writing field demonstrates actual completions, with measured latency below it.
FORM: Native Mac settings utility, chosen from the user's explicit platform and reference. seed: none (brief-pinned native conventions).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
