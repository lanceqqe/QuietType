# QuietType

<!-- impeccable:product-schema 1 -->

## Platform
Native macOS 26+, Apple Silicon.

## Stack
Swift 6, SwiftUI, AppKit, Accessibility, Core ML. Native stack follows the requested Apple Silicon integration.

## Product Purpose
Local predictive typing inspired by Cotypist. Required languages: Russian and English. Apple Intelligence must not be required. Speed and energy efficiency matter.

## Operating Context
The user writes in other Mac applications. Suggestions should be accepted without leaving the text field. A menu bar control pauses assistance; a native settings window provides setup and testing.

## Capabilities and Constraints
Use an independently downloaded multilingual model through Core ML, configured for CPU and Neural Engine. Core ML makes final operator placement decisions. No claims about measured ANE utilization or energy savings without profiling. Accessibility compatibility varies across apps.

## Brand Commitments
Working name QuietType is an implementation assumption, not an established user brand. Use native macOS controls and conventions, Russian interface text, system appearance.

## Evidence on Hand
Reference: https://cotypist.app. No existing code or model assets were supplied. No measured performance claims yet.
